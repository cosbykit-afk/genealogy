# genealogy

Family tree research — the 1 Timothy 1:4 verified-from-scratch build.

This is the **public copy**. It is built only from verified material, and
the living root individual's record is withheld from it (per the owner's
direction). The private working file is not published.

- `1 Timothy 1_4 - verified - public.ged` — the public GEDCOM (5.5.1, UTF-8)
- `verified/build_verified.py` — the seed builder (public-safe variant)
- `verified/VERIFIED.md` — the build rulebook
- `applied/ledger.md` — change ledger for applied research

## Research status (2026-09-30)

- **New anchor: Charlemagne.** The Senlis/Vermandois Pepin line is a dead
  end for now — no independent source for Pepin II → Pepin III (checked
  Britannica, Find-a-Grave). Current work verifies the patrilineal chain:
  Charlemagne → Pepin the Short → Charles Martel → Pepin of Herstal →
  Ansegisel (+ Begga of Landen) → Arnulf of Metz (St. Arnulf), as far back
  as sources allow, plus the downward link Charlemagne → Pepin of Italy
  (Carloman) → Bernard of Italy to join the existing verified tree.
- **Proposals only.** Edits to the verified file require the owner's
  explicit approval — no changes are applied on suggestion alone.

## Method

Verified-from-scratch: every link in the public tree is backed by a source.
The public GEDCOM is rebuilt from the verified material only; the private
working file (with living individuals) is never published.
